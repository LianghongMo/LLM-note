# LLM-note

Notes for Boris Hanin's reading course **Theory of Deep Learning** (Princeton,
Fall 2026): scaling limits, infinite-width training dynamics, feature
learning, and diffusion models, written from a statistical-physics point of view.

**Credit.** The course and its lectures are Boris Hanin's; see the course page
at <https://boris-hanin.github.io/informal-course-2026/>. Notes by Lianghong Mo.

- **Website:** <https://lianghongmo.github.io/LLM-note/> (rendered math and interactive figures)
- **PDF:** [notes/LLM-note.pdf](notes/LLM-note.pdf)

| Lecture | Date | Contents |
|---|---|---|
| [1. Three Questions in Deep-Learning Theory](https://lianghongmo.github.io/LLM-note/lecture1.html) | Sep 10 | Neural networks as function families. Scaling laws and large-network limits (NTK, mean field, DMFT, Gaussian processes). Feature learning, superposition, feature geometry, in-context learning. Diffusion models: forward process, score, denoising score matching, probability-flow ODE. |
| [2. Scaling Limits of Neural Networks](https://lianghongmo.github.io/LLM-note/lecture2.html) | Sep 17 | Deep linear networks and the effective depth ξ = L/N. Neural SDE vs. Neural ODE limits of deep ResNets, and the fractional-Brownian interpolation s_L ∼ L^(−H). High-dimensional ridge regression: Marchenko–Pastur law, exact risk, λ* = γ/SNR. |
| [3. Infinite-Width Training Dynamics](https://lianghongmo.github.io/LLM-note/lecture3.html) | Sep 24 | How initialization and learning rate must scale with width. NTK parametrization (γ = 1): frozen kernel, training as kernel regression. Mean-field parametrization (γ = √N): neurons move O(1), the neuron distribution follows a Wasserstein gradient flow. |

## Repository layout

```
notes/                  LaTeX source, the single source of truth
  main.tex              compiles all lectures into LLM-note.pdf
  lecture1.tex
  lecture2.tex
  lecture3.tex
  figures/make_figures.py   regenerates figures/ridge_gamma3.pdf from the risk formula
tools/build_site.py     LaTeX -> HTML with pandoc; writes index.html and lectureN.html
assets/                 site.css, site.js, figures.js (the interactive figures)
```

The HTML pages are generated; edit the `.tex` files and rebuild.

## Building

```bash
# PDF (run pdflatex twice for the table of contents)
cd notes
python figures/make_figures.py
pdflatex main.tex && pdflatex main.tex && mv main.pdf LLM-note.pdf
cd ..

# Website (needs pandoc >= 2)
python tools/build_site.py
```

A `% WEBFIG: <name>` comment line in a lecture file marks where an interactive
figure goes on the website; it has no effect on the PDF.

To add a lecture: write `notes/lectureN.tex` starting with `\chapter{...}` and a
`keyideas` block, `\include` it in `main.tex`, add an entry to `LECTURES` in
`tools/build_site.py`, and rebuild both.

## Changes from the original note

The text comes from `a-deeplearningnote.tex` in
[LLMnote](https://github.com/LianghongMo/LLMnote). Editorial changes:

- Split into Lecture 1 (overview of the three topics), Lecture 2 (scaling
  limits) and Lecture 3 (infinite-width training dynamics); the headings of
  Lectures 2 and 3 were promoted one level so all lectures share the same
  numbering scheme.
- Added a short "Key ideas" summary at the start of each lecture.
- GELU: `GELU(x) = xΦ(x)` holds exactly (it was written with ≈).
- Footnote on the layer-indexing convention, which differs between the two
  lectures.
- Remark in §1.3.4 on the 1/√m (NTK) versus 1/m (mean-field) normalization and
  why it decides lazy versus feature-learning behaviour.
- Lecture 3: defined the input dimension D in the setup and the mean-field
  velocity 𝓜(ϑ, μ) in §3.7, which were used without a definition.
- The pgfplots figure in Lecture 2 is now generated by matplotlib from the
  asymptotic risk formula, so the PDF compiles without pgfplots. The curve is
  unchanged: R(λ* = 3) = 0.847127 for γ = 3, r² = σ² = 1.
