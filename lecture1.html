Lecture 1

Three Questions in Deep-Learning Theory

Neural networks as parametrized families of functions, and the three questions the notes are built around: what simple theory emerges at large scale, what features training discovers, and how a diffusion model learns and samples an entire distribution.

\(\text{Architecture}+\text{Data}+\text{Optimization}\;\Longrightarrow\;f_{\theta}\)

Key ideas

  • A neural network is a parametrized family of functions; what it learns is fixed jointly by the architecture, the data, and the optimization algorithm.

  • Scaling: which simple effective theory emerges as \(N,n,L,W,C\to\infty\) (NTK, mean field, DMFT, Gaussian processes), and why these limits need not commute.

  • Feature learning: a network learns the feature map \(\Phi_\theta(x)\) itself, not only its coefficients; features are directions in activation space and can be stored in superposition.

  • Diffusion: learning the score \(\nabla_x\log\rho_t\) by denoising is enough to reverse a noising process and sample from \(\rho_{\mathrm{data}}\).

1.1 Introduction#

A useful viewpoint is that a neural network is a parametrized family of functions. We choose an architecture, which determines a family \[\left\{ f_\theta:\mathcal X\rightarrow\mathcal Y \right\}_{\theta\in\Theta},\] and learning consists of selecting the parameter \(\theta\) using data.

Thus there are three conceptually distinct ingredients:

  1. the architecture, which specifies the function class;

  2. the data, which provide information about the unknown target;

  3. the optimization algorithm, which determines which member of the function class is actually learned.

One of the central questions in the theory of neural networks is therefore \[\boxed{ \text{Architecture} + \text{Data} + \text{Optimization} \quad \Longrightarrow \quad \text{Learned function / representation}. }\]

1.1.1 Definition of Neural Networks#

1.1.1.1 Fully connected neural networks#

Consider an input \[x\in\mathbb R^{N_0}.\] Define \[z^{(0)}(x)=x.\] A fully connected neural network with \(L+1\) layers is recursively defined by \[z^{(\ell+1)}(x) = W^{(\ell+1)} \phi\!\left(z^{(\ell)}(x)\right) + b^{(\ell+1)}, \qquad \ell=0,\ldots,L,\] where \[W^{(\ell+1)} \in \mathbb R^{N_{\ell+1}\times N_\ell}, \qquad b^{(\ell+1)} \in \mathbb R^{N_{\ell+1}},\] and \(\phi\) is a nonlinear activation function applied componentwise.1

Typical choices include \[\begin{aligned} \mathrm{ReLU}(x)&=\max(0,x),\\ \tanh(x)&=\frac{e^x-e^{-x}}{e^x+e^{-x}},\\ \mathrm{GELU}(x)&=x\Phi(x),\end{aligned}\] where \(\Phi\) is the standard Gaussian cumulative distribution function.

The output of the network is \[f_\theta(x) \equiv z^{(L+1)}(x),\] where the parameter set is \[\theta = \left\{ W^{(1)},\ldots,W^{(L+1)}, b^{(1)},\ldots,b^{(L+1)} \right\}.\]

The nonlinear activation is essential. Without \(\phi\), a composition of linear layers would still be only a linear transformation: \[W^{(L)}W^{(L-1)}\cdots W^{(1)}x = W_{\mathrm{eff}}x.\]

1.1.1.2 Residual neural networks#

Instead of replacing the current representation at every layer, a residual network learns a correction: \[z^{(\ell+1)} = z^{(\ell)} + F_{\theta_\ell}\!\left(z^{(\ell)}\right).\]

A typical residual block is \[F_{\theta_\ell}(z) = W_2^{(\ell)} \phi\!\left( W_1^{(\ell)}z+b_1^{(\ell)} \right) + b_2^{(\ell)}.\]

Therefore, \[z^{(\ell+1)} = z^{(\ell)} + W_2^{(\ell)} \phi\!\left( W_1^{(\ell)}z^{(\ell)} + b_1^{(\ell)} \right) + b_2^{(\ell)}.\]

The important physical picture is that each layer makes only an incremental update, \[\Delta z^{(\ell)} = F_{\theta_\ell}(z^{(\ell)}).\]

In a formal continuum-depth limit, a residual network resembles a dynamical system, \[\frac{dz(t)}{dt} = F_{\theta(t)}(z(t)),\] which motivates the connection between residual networks and differential equations.

1.1.2 How Neural Networks Are Used#

Suppose there is an unknown target function \[f:\mathcal X\rightarrow\mathcal Y.\] We observe a training dataset \[\mathcal D = \left\{ (x_i,y_i) \right\}_{i=1}^{n}, \qquad y_i=f(x_i),\] where \(n\) denotes the number of training samples.

The standard supervised-learning procedure is:

  1. Data: observe \[\left\{ (x_i,f(x_i)) \right\}_{i=1}^n.\] The goal is to infer the unknown function \(f\) from finitely many observations.

  2. Initialization: choose an initial parameter \[\theta_0 \sim P_{\mathrm{init}}.\]

  3. Optimization: minimize a loss function. For regression, a common choice is \[\mathcal L(\theta) = \frac{1}{2n} \sum_{i=1}^n \left\| f(x_i)-f_\theta(x_i) \right\|^2.\]

    Gradient descent gives \[\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal L(\theta_t),\] where \(\eta\) is the learning rate.

    In practice one usually uses stochastic gradient descent, \[\theta_{t+1} = \theta_t - \eta \widehat{\nabla_\theta \mathcal L},\] where the gradient is estimated from a minibatch.

  4. Generalization / test: for a new point \(x_{\mathrm{new}}\) that was not in the training set, ask whether \[f(x_{\mathrm{new}}) \approx f_{\theta_{\mathrm{learned}}}(x_{\mathrm{new}}).\]

A neural network is therefore not useful merely because it can fit the training data. The central problem is whether it can generalize.

1.1.3 Three Main Topics#

We focus on three broad theoretical questions:

  1. Scaling laws and large-network limits: What happens as the model size, dataset size, and computational budget become very large?

  2. Feature learning and representation learning: What internal representations does the neural network learn, and why do these representations help generalization?

  3. Generative models, especially diffusion models: How can a neural network learn an entire high-dimensional probability distribution and generate new samples from it?

1.2 Topic I: Scaling Laws and Large-Network Limits#

1.2.1 Basic Questions#

Modern neural networks involve several potentially large parameters: \[\begin{aligned} N &= \text{number of model parameters},\\ n &= \text{number of training samples},\\ L &= \text{depth},\\ W &= \text{width},\\ C &= \text{computational budget}.\end{aligned}\]

The theoretical problem resembles statistical mechanics: instead of studying one finite neural network in detail, we would like to identify simple laws that emerge in appropriate large-scale limits.

Some central questions are:

  1. What happens when \[N,n,L,W,C\rightarrow\infty?\]

    These limits need not commute. For example, \[\lim_{n\rightarrow\infty} \lim_{W\rightarrow\infty}\] may describe a different regime from \[\lim_{W\rightarrow\infty} \lim_{n\rightarrow\infty}.\]

    Therefore the interesting object is often a joint scaling limit, analogous to a thermodynamic limit.

  2. Does a complicated neural network reduce to a simpler effective theory in such a limit?

  3. Can performance at very large scale be predicted from experiments at relatively small scale?

  4. Which resource is the bottleneck: \[\text{model size},\qquad \text{data},\qquad \text{optimization},\qquad \text{compute}?\]

  5. When does increasing the model size actually improve performance, and when does performance saturate?

1.2.2 Empirical Scaling Laws#

Empirically, many machine-learning systems approximately obey power-law scaling over a substantial range of scales.

For example, test loss may behave as \[\boxed{ \mathcal L(C) = \mathcal L_\infty + A C^{-\beta}, }\] where \[C=\text{compute},\] \(\beta>0\) is a scaling exponent, and \(\mathcal L_\infty\) is an irreducible loss floor.

Similarly one may study \[\begin{aligned} \mathcal L(N) &\approx \mathcal L_\infty + A_N N^{-\alpha_N}, \\ \mathcal L(n) &\approx \mathcal L_\infty + A_n n^{-\alpha_n}.\end{aligned}\]

More generally, \[\mathcal L = \mathcal L(N,n,C,\ldots).\]

The interesting theoretical questions are not only whether these power laws exist, but also:

  1. why power laws emerge;

  2. whether the exponents are universal;

  3. how the exponents depend on the data distribution and architecture;

  4. how to optimally allocate a fixed computational budget between increasing \(N\), increasing \(n\), and training for longer.

1.2.3 Optimization, Approximation, and Data Errors#

It is useful to conceptually decompose the total error into several pieces: \[\mathcal E_{\mathrm{total}} \sim \mathcal E_{\mathrm{approx}} + \mathcal E_{\mathrm{estimation}} + \mathcal E_{\mathrm{optimization}}.\]

Here:

  • \(\mathcal E_{\mathrm{approx}}\) measures whether the architecture is expressive enough to represent the desired function;

  • \(\mathcal E_{\mathrm{estimation}}\) arises because the training dataset is finite;

  • \(\mathcal E_{\mathrm{optimization}}\) measures whether the optimizer succeeds in finding a good parameter configuration.

Scaling the number of parameters only directly attacks the first of these. Therefore increasing model size alone need not always improve performance.

1.2.4 Theoretical Approaches#

1.2.4.1 Neural Tangent Kernel#

Consider the network output \[f_\theta(x).\] Linearize it around the initialization \(\theta_0\): \[f_\theta(x) \approx f_{\theta_0}(x) + \nabla_\theta f_{\theta_0}(x)^T (\theta-\theta_0).\]

Define the Neural Tangent Kernel \[K_{\mathrm{NTK}}(x,x') = \nabla_\theta f_{\theta_0}(x)^T \nabla_\theta f_{\theta_0}(x').\]

In an appropriate infinite-width limit, the NTK becomes approximately deterministic and changes very little during training.

The nonlinear neural-network training problem is then reduced to an effective kernel regression problem.

The physical picture is \[\boxed{ \text{very wide network} \quad\Rightarrow\quad \text{approximately fixed features} + \text{linearized dynamics}. }\]

This regime is often called the lazy-training regime.

A major limitation is that realistic neural networks often exhibit substantial feature learning, whereas the simplest NTK limit freezes the features.

1.2.4.2 Mean-Field Theory#

Another large-width limit treats individual neurons as interacting particles.

Consider a two-layer network \[f_m(x) = \frac{1}{m} \sum_{j=1}^m a_j \sigma(w_j^T x).\]

Instead of following every neuron separately, define an empirical distribution of neuron parameters, \[\rho_m(a,w) = \frac{1}{m} \sum_{j=1}^m \delta(a-a_j) \delta(w-w_j).\]

As \[m\rightarrow\infty,\] one can sometimes derive a deterministic evolution equation for \[\rho(a,w,t).\]

Schematically, \[\partial_t \rho = \mathcal F[\rho].\]

This is analogous to the passage \[\text{many particles} \rightarrow \text{continuum density}\] in statistical mechanics.

Unlike the simplest NTK regime, the distribution of features \(w\) can evolve, so mean-field theory can describe genuine feature learning.

1.2.4.3 Dynamical Mean-Field Theory#

For sufficiently complicated random neural networks, especially deep networks or recurrent systems, one can seek an effective stochastic description of a typical neuron or feature.

The philosophy is analogous to dynamical mean-field theory in many-body physics: \[\boxed{ \text{high-dimensional interacting system} \rightarrow \text{self-consistent effective single-site dynamics}. }\]

Instead of tracking every neuron explicitly, one derives self-consistency equations for quantities such as \[\begin{aligned} C(t,t') &= \left\langle z(t)z(t') \right\rangle, \\ R(t,t') &= \frac{\delta \langle z(t)\rangle} {\delta h(t')}.\end{aligned}\]

These quantities play roles analogous to correlation and response functions in statistical physics.

1.2.4.4 Bayesian Inference#

A different viewpoint is to place a prior distribution on the network parameters, \[P(\theta),\] and use Bayes’ rule: \[P(\theta\mid\mathcal D) = \frac{ P(\mathcal D\mid\theta)P(\theta) }{ P(\mathcal D) }.\]

Predictions are then obtained by averaging over the posterior: \[P(y_\ast\mid x_\ast,\mathcal D) = \int d\theta\, P(y_\ast\mid x_\ast,\theta) P(\theta\mid\mathcal D).\]

For some infinitely wide neural networks, the prior over functions becomes a Gaussian process, \[f(x)\sim\mathrm{GP}(0,K(x,x')).\]

This provides another analytically tractable infinite-width limit.

1.2.5 Important Distinction: Scaling Is Not Just “More Parameters”#

When discussing scaling, one should distinguish several directions: \[\begin{aligned} \text{model scaling} &: N\rightarrow\infty, \\ \text{data scaling} &: n\rightarrow\infty, \\ \text{compute scaling} &: C\rightarrow\infty, \\ \text{context / horizon scaling} &: T\rightarrow\infty.\end{aligned}\]

Good scaling often requires these quantities to grow together.

Thus, \[\boxed{ \text{Scaling up the model} \neq \text{scaling up the learning problem}. }\]

1.3 Topic II: Feature Learning and Representation Learning#

1.3.1 Linear Models#

Before studying neural networks, consider a linear model in a fixed feature space: \[f_\theta(x) = \theta^T\Phi(x) = \sum_{j=1}^{M} \theta_j\varphi_j(x),\] where \[\Phi(x) = \begin{pmatrix} \varphi_1(x)\\ \vdots\\ \varphi_M(x) \end{pmatrix}\] is a feature map.

The important point is that the features \[\varphi_j(x)\] are fixed. Learning only determines their coefficients \(\theta_j\).

Therefore a linear model solves \[\boxed{ \text{fixed representation} + \text{learned linear coefficients}. }\]

1.3.2 Neural Networks Learn the Features#

Consider the final layer of a neural network: \[f_i(x;\theta) = \sum_{j=1}^{N_L} W_{ij}^{(L+1)} \phi_j(x;\theta),\] where \[\phi_j(x;\theta) = \phi\!\left( z_j^{(L)}(x;\theta) \right).\]

From the perspective of the final layer, this looks exactly like a linear model: \[f(x) = W^{(L+1)} \Phi_\theta(x).\]

The crucial difference is \[\boxed{ \Phi_\theta(x) \text{ itself depends on the learned parameters.} }\]

Thus neural-network training does two things simultaneously:

  1. it learns how to combine features;

  2. it learns what the features themselves should be.

This is the basic meaning of representation learning.

1.3.3 The Central Feature-Learning Question#

The basic theoretical problem is:

\[\boxed{ \text{Data} + \text{Architecture} + \text{Optimization} + \text{Initialization} \rightarrow \text{Learned features}. }\]

More explicitly, we would like to understand \[\Phi_{\theta_t}(x)\] as a function of training time \(t\).

Questions include:

  1. Which features emerge first during training?

  2. Which properties of the data determine the learned representation?

  3. Why are some features reused across many tasks?

  4. When are representations sparse or distributed?

  5. When does the network discover semantic concepts?

  6. How do learned representations change with width and depth?

1.3.4 A Minimal Two-Layer Model#

Consider \[f(x;t) = \frac{1}{\sqrt m} \sum_{j=1}^{m} a_j(t) \sigma\!\left( w_j(t)^T x \right).\]

There are two qualitatively different kinds of learning.

If only \[a_j(t)\] change while \[w_j(t)\approx w_j(0),\] then the network is approximately learning a linear combination of fixed features \[\sigma(w_j(0)^T x).\]

By contrast, if \[w_j(t)\] move substantially, the features themselves change: \[\sigma(w_j(0)^Tx) \longrightarrow \sigma(w_j(t)^Tx).\]

This is genuine feature learning.

This also makes the connection with Topic I clear: \[\boxed{ \text{NTK / lazy limit} \approx \text{weak feature learning}, }\] whereas other scaling limits can preserve nontrivial feature dynamics.

Remark (parametrization).

The prefactor \(1/\sqrt m\) used here is the NTK scaling, while the mean-field model of Section 1.2.4.2 uses \(1/m\). With \(1/\sqrt m\) and an \(O(1)\) learning rate, each \(w_j\) moves by only \(O(1/\sqrt m)\) during training, so the features freeze as \(m\to\infty\). With \(1/m\) and a learning rate scaled up by \(m\), each \(w_j\) moves by \(O(1)\). The choice of normalization is therefore what selects lazy versus feature-learning behavior; Lecture 3 derives both limits.

1.3.5 What Is a Semantic Feature?#

Suppose a vision model is given an image of the Golden Gate Bridge.

At the raw-input level, the image consists only of pixel values: \[x = (x_1,x_2,\ldots,x_N).\]

A low-level feature might detect: \[\text{edges},\quad \text{colors},\quad \text{textures}.\]

A higher-level representation may encode concepts such as \[\text{bridge}, \qquad \text{suspension bridge}, \qquad \text{Golden Gate Bridge}, \qquad \text{San Francisco}.\]

These are called semantic features because they correspond to meaningful concepts rather than simple local properties of the input.

An important question is whether such concepts correspond to individual neurons or to directions in a high-dimensional representation space.

1.3.6 Distributed Representations and Superposition#

A naive picture is \[\text{one neuron} \leftrightarrow \text{one concept}.\]

However, modern neural networks often appear to use distributed representations.

A feature may correspond to a direction \[v_\alpha \in \mathbb R^d\] in activation space, rather than to a single neuron.

An activation vector may schematically be written as \[h(x) \approx \sum_\alpha c_\alpha(x)v_\alpha.\]

If the number of useful features is larger than the activation dimension, the network may store multiple features in non-orthogonal directions: \[v_\alpha^T v_\beta \neq 0.\]

This phenomenon is often called superposition.

The rough idea is \[\boxed{ \text{number of useful features} > \text{number of available neurons} }\] so the network compresses many features into a smaller-dimensional space.

This can lead to polysemantic neurons, where one neuron participates in representing several apparently unrelated concepts.

1.3.7 Feature Geometry#

Rather than analyzing individual neurons, it is often more useful to study the geometry of representation space.

Let \[h_\theta(x)\in\mathbb R^d\] denote the learned representation.

Then one may study distances \[d_\theta(x,x') = \left\| h_\theta(x)-h_\theta(x') \right\|,\] similarities \[K_\theta(x,x') = h_\theta(x)^T h_\theta(x'),\] or covariance matrices \[C = \mathbb E_x \left[ h_\theta(x)h_\theta(x)^T \right].\]

The spectrum of \(C\) provides information about the effective dimensionality of the learned representation.

1.3.8 Transformers and In-Context Learning#

Feature learning becomes particularly interesting in transformers.

A transformer maps a sequence \[x_1,\ldots,x_T\] to internal representations \[h_1^{(\ell)},\ldots,h_T^{(\ell)}.\]

Self-attention performs \[\begin{aligned} q_i &= W_Q h_i,\\ k_j &= W_K h_j,\\ v_j &= W_V h_j,\end{aligned}\] followed by \[\mathrm{Attention}(i) = \sum_j A_{ij}v_j,\] with \[A_{ij} = \frac{ \exp(q_i^Tk_j/\sqrt d) }{ \sum_{j'} \exp(q_i^Tk_{j'}/\sqrt d) }.\]

Unlike a fixed feature map, the representation of one token depends on the other tokens in the context.

This raises the question of in-context learning: how can the forward pass of a trained transformer implement something that resembles a learning algorithm?

Schematically, \[\text{context examples} \rightarrow \text{internal representation} \rightarrow \text{new prediction}.\]

One viewpoint is that training does not merely teach the model a fixed input-output function; it can teach the model an algorithm for extracting a task from context.

1.4 Topic III: Diffusion Models#

1.4.1 Generative Modeling#

Suppose the data are drawn from an unknown high-dimensional distribution \[x_0\sim \rho_0(x).\]

For example, \(x_0\) may be an image.

The goal of a generative model is not merely to predict a label. Instead, we want to generate a new sample \[x_{\mathrm{new}} \sim \rho_0.\]

The main difficulty is that \(\rho_0(x)\) can be an extremely complicated distribution in a very high-dimensional space.

1.4.2 Forward Diffusion Process#

Diffusion models introduce a continuous family of distributions \[\rho_t, \qquad t\in[0,T],\] such that \[\rho_{t=0} = \rho_{\mathrm{data}},\] while \[\rho_T \approx \mathcal N(0,I).\]

The forward process gradually adds Gaussian noise.

A common parametrization is \[\boxed{ x_t = \alpha_t x_0 + \sigma_t\epsilon, \qquad \epsilon\sim\mathcal N(0,I). }\]

Initially, \[\alpha_0\approx1, \qquad \sigma_0\approx0,\] so \[x_t\approx x_0.\]

At sufficiently large \(t\), \[\alpha_T\approx0, \qquad \sigma_T\approx1,\] so \[x_T\approx\epsilon \sim\mathcal N(0,I).\]

Thus, \[\boxed{ \text{complicated data distribution} \rightarrow \text{simple Gaussian distribution}. }\]

1.4.3 The Score Function#

Define the score of the intermediate distribution \(\rho_t\) by \[\boxed{ s_t(x) = \nabla_x \log \rho_t(x). }\]

The score is a vector field in data space.

Intuitively, \(s_t(x)\) points toward directions in which the probability density increases most rapidly.

For a one-dimensional Gaussian, \[\rho(x) \propto e^{-x^2/(2\sigma^2)},\] we have \[s(x) = \frac{d}{dx}\log\rho(x) = -\frac{x}{\sigma^2}.\]

Therefore the score points back toward the high-probability region near \(x=0\).

1.4.4 Why Is the Score Enough?#

Suppose the forward diffusion is described by the stochastic differential equation \[dx = f(x,t)\,dt + g(t)\,dW_t.\]

The evolution of the probability density is described by a Fokker–Planck equation.

Remarkably, the corresponding reverse-time stochastic dynamics can be written in terms of the score: \[dx = \left[ f(x,t) - g(t)^2 \nabla_x\log\rho_t(x) \right]dt + g(t)d\overline W_t,\] where the equation is integrated from \(t=T\) back toward \(t=0\).

Therefore, if we know \[s_t(x) = \nabla_x\log\rho_t(x)\] for every \(t\), we can reverse the noising process.

The central idea is consequently \[\boxed{ \text{learn the score} \quad\Longrightarrow\quad \text{reverse diffusion} \quad\Longrightarrow\quad \text{generate data}. }\]

1.4.5 Learning the Score#

Introduce a neural network \[s_\theta(x,t)\] that approximates \[\nabla_x\log\rho_t(x).\]

For the Gaussian corruption \[x_t = \alpha_t x_0 + \sigma_t\epsilon,\] the conditional distribution is \[p(x_t\mid x_0) = \mathcal N( \alpha_t x_0, \sigma_t^2 I ).\]

Its score is known exactly: \[\nabla_{x_t} \log p(x_t\mid x_0) = - \frac{ x_t-\alpha_t x_0 }{ \sigma_t^2 }.\]

Since \[x_t-\alpha_t x_0 = \sigma_t\epsilon,\] this becomes \[\nabla_{x_t} \log p(x_t\mid x_0) = - \frac{\epsilon}{\sigma_t}.\]

Therefore one can train the network using denoising score matching: \[\mathcal L_{\mathrm{score}}(\theta) = \mathbb E_{ t,x_0,\epsilon } \left[ \lambda(t) \left\| s_\theta(x_t,t) + \frac{\epsilon}{\sigma_t} \right\|^2 \right].\]

Thus the training problem can be reduced to a supervised regression problem with artificially generated Gaussian noise.

1.4.6 Equivalent Noise-Prediction Formulation#

Instead of directly predicting the score, many diffusion models predict the noise \[\epsilon_\theta(x_t,t).\]

Since \[s_t(x_t) \sim - \frac{\epsilon}{\sigma_t},\] the two representations are directly related: \[s_\theta(x_t,t) = - \frac{ \epsilon_\theta(x_t,t) }{ \sigma_t }.\]

The corresponding loss is approximately \[\mathcal L_\epsilon = \mathbb E \left[ \left\| \epsilon - \epsilon_\theta(x_t,t) \right\|^2 \right].\]

1.4.7 Probability-Flow ODE#

The stochastic reverse dynamics are not the only way to generate samples.

The same family of marginal distributions \(\rho_t\) can also be reproduced by a deterministic probability-flow ODE, \[\frac{dx}{dt} = f(x,t) - \frac{1}{2} g(t)^2 s_t(x).\]

Thus diffusion models can be understood either as \[\text{stochastic reverse dynamics}\] or as \[\text{deterministic transport through probability space}.\]

This also provides a connection to flow-based generative models and flow matching.

1.4.8 Geometrical Picture#

At large noise, \[\rho_T(x) \approx \mathcal N(0,I),\] which is simple.

As \(t\) decreases, the score field gradually guides samples toward the high-probability regions of the data distribution.

Schematically, \[\text{Gaussian noise} \rightarrow \text{coarse structure} \rightarrow \text{objects} \rightarrow \text{fine details}.\]

In this sense, the neural network learns a time-dependent vector field \[s_\theta(x,t)\] that describes the geometry of the probability distribution at different noise scales.

1.4.9 Main Questions for Diffusion Models#

Important theoretical questions include:

  1. Why is the score easier to learn than the probability density itself?

  2. Why does adding noise make the learning problem easier?

  3. How accurately must the score be learned in order to generate accurate samples?

  4. How does error accumulate during the reverse process?

  5. Why do diffusion models scale so effectively with model size and data?

  6. What representations are learned by the denoising network?

  7. What is the relation between diffusion models, optimal transport, normalizing flows, and flow matching?

  8. How many reverse-time steps are fundamentally necessary?

  9. Which aspects of the data distribution are learned at large noise and which are learned only at small noise?

1.5 Relations Between the Three Topics#

Although scaling laws, feature learning, and diffusion models initially look like separate topics, they are closely connected.

1.5.1 Scaling and Feature Learning#

The infinite-width limit used in NTK theory can suppress feature learning: \[\text{width}\rightarrow\infty \quad\Rightarrow\quad \text{features approximately frozen}.\]

Therefore an important question is which scaling limit retains the rich feature learning observed in practical neural networks.

This illustrates why different limits need not commute.

1.5.2 Feature Learning and Diffusion#

A diffusion model is trained to estimate \[s_t(x) = \nabla_x\log\rho_t(x)\] at many noise levels.

To do this, the network must learn useful internal representations of the data.

At large \(t\), these representations may encode coarse global structure, whereas at small \(t\) they must encode increasingly fine details.

Thus diffusion models provide a natural laboratory for studying how representations depend on scale.

1.5.3 Scaling and Generative Modeling#

A generative model must represent an entire probability distribution rather than merely a decision boundary.

This raises particularly sharp scaling questions: \[\text{How much model capacity and data are required to represent} \quad \rho_{\mathrm{data}}?\]

One may therefore study scaling laws such as \[\mathcal L_{\mathrm{gen}} = \mathcal L(N,n,C),\] and ask whether the same scaling ideas observed in supervised learning also govern modern generative models.

1.6 Big Picture#

The three topics can be summarized as follows.

Topic Central Question
Scaling What simple theory emerges when neural networks become very large?
Feature learning What internal representation does training discover?
Diffusion How can a neural network learn and sample from an entire distribution?

A common theme is the search for an effective theory of learning: \[\boxed{ \text{microscopic parameter dynamics} \quad\longrightarrow\quad \text{macroscopic laws of learning}. }\]

From a statistical-physics perspective, neural networks are particularly interesting because they are large interacting dynamical systems whose effective degrees of freedom, representations, and scaling laws are themselves learned from data.
